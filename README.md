# Capturius

Lightweight Windows screenshot tool with a built-in editor. Capture full screen, desktop, active window, or a custom region. Annotate with arrows, shapes, and text. Pick colors from screen. Runs in the system tray.

## Features

- **Full Screen** — capture the entire screen `PrintScreen`
- **Desktop** — full screen without taskbar `Shift+PrintScreen`
- **Active Window** — capture the focused window `Alt+PrintScreen`
- **Region** — select a custom area `Ctrl+PrintScreen`
- **Color Picker** — pick any color from the screen `Ctrl+Shift+C`
- **Editor** — annotate screenshots with arrows, rectangles, and text
- **System tray** — runs quietly in the background

## Requirements

- Windows 10 or later (x64)
